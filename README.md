# -FPGA-CNN-
本作品面向端侧智能视觉，基于国产安路FPGA，打通了摄像头采集、图像预处理、神经网络推理与HDMI显示的完整链路，运行时无需电脑参与识别计算。  系统能够实时识别取景区域内的单个手写数字，并同屏显示网络输入预览、识别结果、运行计数和采集、识别速率，使处理过程直观可见。  核心技术是轻量化神经网络的硬件部署。我们通过八位权重量化、单乘累加单元时分复用和片上存储优化，在有限资源下实现了完整的整数推理，完成了算法与硬件资源的协同设计。  目前，系统已完成上板验证，摄像头采集约为每秒六十帧，CNN识别更新约为每秒六十次。整数模型在MNIST完整一万幅测试图像上的准确率达到百分之九十七点四二，已有一百幅RTL仿真输出与整数参考模型逐值一致。
